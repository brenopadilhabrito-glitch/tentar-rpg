# Verdejante

RPG 2D de mundo aberto executado diretamente no navegador.

## Sistemas do jogo

- Escolha entre treze raças e treze classes, com atributos, técnicas e equipamentos próprios.
- Explore dez biomas com cenários variados. A dificuldade e a frequência dos inimigos aumentam quanto mais longe você se afasta do ponto inicial.
- Encontre dez masmorras com 12 andares e chefes próprios; cada região oferece recompensas e materiais diferentes.
- Organize armas, armadura, capacete, escudo, duas luvas, botas, calças, colar, cinto e dois braceletes na mochila.
- Derrote inimigos para coletar materiais. Aproxime-se da **Forja**, ao sul do ponto inicial, e pressione **E** para fabricar armas, roupas, acessórios e poções.
- Use **WASD** ou as setas para se mover, **E** para interagir, **clique** ou **Espaço** para atacar, e **1–5** para habilidades.
